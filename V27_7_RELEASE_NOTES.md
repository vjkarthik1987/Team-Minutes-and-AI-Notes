# v27.7 — Thread Creation Modal + Better Teams-Style Summaries

## Thread creation
- Replaced the inline thread form with a cleaner **Create thread** button.
- The button opens a modal asking for:
  - Thread name
  - Outcome
  - Client / area
  - Status
  - Collaborators
- Collaborator search starts after 3 typed characters.
- Selected collaborators appear as removable chips.
- The creator is automatically added as a collaborator/member in the backend.

## Thread search
- Threads page search is now dynamic on the page.
- Type 3+ characters to instantly filter by thread name, outcome, client/area, status, owner, collaborator, or tags.

## Summary generation
- Strengthened the summarization pipeline while keeping the existing OpenAI path.
- Added a final Teams-benchmark editor pass to repair thin summaries.
- The summary prompt now explicitly targets the Microsoft Teams style:
  - `Generated by AI...`
  - `Meeting notes:`
  - topic-wise themes
  - named subtopics
  - richer follow-up tasks
- Improved instructions for shared-login speaker attribution.
- More aggressive action-item capture from explicit and strongly implied follow-ups.

## Notes
- Existing saved summaries must be regenerated to use the v27.7 logic.
