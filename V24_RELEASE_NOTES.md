# v24 Release Notes — Minimized Global Copilot

## UX change
- Kili / AI meeting memory is now minimized by default on user pages.
- A floating **Ask Kili** button opens the copilot only when needed.
- The copilot appears as a right-side slide-out drawer with a close button and Escape-key close support.
- Main page content now uses the freed-up width instead of reserving a permanent chatbot column.

## Full-width work pages
- Actions, Threads, and People now benefit from the wider workspace layout.
- The global copilot is still available everywhere through the floating button.

## Compatibility
- No backend model or route changes.
- Existing chat history, chat modes, retrieval, answer generation, source trace, and clear chat behavior are retained.
