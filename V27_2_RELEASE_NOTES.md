# V27.2 Release Notes

Simple meeting experience polish.

## Added
- Full-width search bar on `/user/meetings`.
- Incremental pagination / load-more pattern for the meetings page.
- Transcript download button and `.txt` download route.
- AI summary download button and `.txt` download route.
- Structured AI summary display using section cards.

## Changed
- Renamed user-facing brand from Minutes to Ms. Minutes.
- Disabled underline hover on the Ms. Minutes logo/brand link.
- Meeting page now renders fewer cards initially to keep the page lighter.

## Preserved
- Admin views remain untouched.
- Same MongoDB models and Office 365 login flow.
