# v24.1 Release Notes

## Home redesign
- Rebuilt Home as two primary sections: **Threads** and **Meetings**.
- Threads panel shows a scrollable list of threads the signed-in user created, owns, can view, contributes to, or is part of.
- Meetings panel has three tabs: **Yesterday**, **Today**, and **Tomorrow**.
- On Fridays, the Tomorrow tab expands through Monday so weekend/Monday preparation is visible before the weekend.

## Copilot UX
- Made the slide-out copilot close button more prominent with stronger contrast, larger size, and hover feedback.

## Notes
- Built on v24 minimized global copilot.
- No database migration required.
