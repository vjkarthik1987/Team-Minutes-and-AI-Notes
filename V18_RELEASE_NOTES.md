# v18 Clean Baseline

This is a clean pushable baseline built from the latest v17.4 collaborator/assistant build.

## Included
- Executive intelligence chatbot baseline
- Collaborator and assistant screens
- Add notes on behalf of another user
- Thread/context/action models
- Personal and org memory support
- Railway-ready Node 20 configuration
- Clean npm registry configuration

## Deployment notes
- Use Node 20 on Railway.
- Railway variable recommended: `NIXPACKS_NODE_VERSION=20`.
- Do not commit `.env`, `node_modules`, or `certs`.
