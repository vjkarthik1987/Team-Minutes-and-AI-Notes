# v17.3 — Collaborator & Assistant Screens Enabled

## Included

- Added dedicated **Collaborators** screen at `/user/collaborators`.
- Added dedicated **Assistant workbench** at `/user/assistant`.
- Added sidebar links for:
  - Assistant work
  - Collaborators
- Collaborator screen now shows:
  - Your collaborators
  - Add collaborator form
  - How collaborator permissions work
  - People who have added you as collaborator/assistant/delegate
- Assistant workbench now shows:
  - People who delegated to you
  - Threads where you can contribute
  - Open actions assigned to you
  - Quick add context form
  - Quick escalation form
- Settings now links clearly to collaborator and assistant screens.
- Improved collaborator/assistant screen styling, padding, action buttons, and mobile behavior.

## Important behavior

A collaborator is not a global admin. They can contribute only when added to a thread or where ACL permissions allow it.
