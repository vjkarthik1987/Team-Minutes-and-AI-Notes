# v25.4.1 — Rich Briefings and Thread Workspace Polish

- Briefings now behave like long personal notes/letters.
- `@` thread picker added for related thread references.
- `#` lines are treated as action requests and highlighted for the recipient.
- Thread notes show timestamps in the diary.
- Generated insights can be reviewed and saved into the diary via Quick Insight.
- Removed the old Save Human Insight block; Quick Insight is now next to Add Context.
- Home thread links open external dashboard links instead of hijacking to the thread page.
- Home thread cards now have visible light grey borders.
- Status and health are styled as pills.
- Threads moved directly after Home in the sidebar.
