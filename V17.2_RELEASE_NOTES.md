# v17.2 — Executive Intelligence Engine

This release upgrades Kili from meeting-answering into Chief-of-Staff style execution intelligence.

## Included

- Deterministic intent router so questions like "What should be my focus today?" never route to action assignment.
- Executive briefing intent for focus, attention, priority, silent risk and daily brief questions.
- Chief-of-Staff briefing engine using meetings, actions, notes, threads and memory.
- Meeting criticality scoring based on overdue actions, linked context, thread linkage, release/blocker/risk language and executive pressure.
- Action criticality scoring based on due date, priority, staleness, blocker language and ownership gaps.
- Thread health scoring using status, risks, open actions, recurring-chain signals and stale updates.
- Silent risk detection for overdue actions and at-risk/blocked threads.
- Upgraded prompt that prohibits generic management filler and forces concrete evidence-based leadership guidance.
- AI fallback remains deterministic, but now uses ranked executive signals instead of raw lists.

## Key bug fixed

Before v17.2:

> What should be my focus for today?

could be misread as an incomplete action assignment.

After v17.2:

It routes to `executive_briefing` and returns a Chief-of-Staff style daily focus brief.
