# v15 - Outcome-Centric AI Threads

This release turns Threads into living outcome workspaces rather than simple meeting links.

## v15.0 - Outcome Thread Foundation
- Expanded MeetingThread model with objective, desired outcome, status, priority, owner, members and ACL.
- Added thread detail page.
- Added editable thread outcome/status metadata.
- Added linked meetings as evidence/context.

## v15.1 - Thread Memory
- Added notes / discussion log entries.
- Added decisions.
- Added risks with severity.
- Added thread-level action items with owner and due date.
- Added unified timeline across notes, decisions, risks, actions and status updates.
- Added thread-scoped chatbot behavior from the thread page.

## v15.2 - AI Outcome Intelligence
- Added AI thread memory refresh using linked meetings plus manual thread entries.
- Added executive memory, current state, changed items, risks, actions, recommended status and health score.
- Added health label and AI suggested status fields.

## Principle
Meetings are events. Threads are continuity. Outcomes are the purpose.
